# GitHub Slideshow Framework - Complete Documentation

Welcome to the comprehensive documentation for the GitHub Slideshow Framework, a Jekyll-based presentation system built on top of Reveal.js.

## 📚 Documentation Overview

This documentation suite provides complete coverage of all public APIs, functions, components, and usage patterns for the GitHub Slideshow framework. Whether you're a beginner getting started or an advanced user looking to customize and extend the framework, you'll find everything you need here.

### What's Included

- **Complete API Reference** - Every configuration option, component, and method documented
- **Practical Examples** - Real-world usage patterns and implementation guides  
- **Component Documentation** - Detailed breakdown of all layouts, includes, and scripts
- **Quick Reference** - Cheat sheet for rapid development
- **Best Practices** - Performance, accessibility, and deployment guidance
